name: create-pr
description: PR テンプレートに従って、日本語のタイトルと本文で Draft PR を作成し、自分自身をアサインする。PR の作成を頼まれたときに使う。
---

現在のブランチから、`.github/PULL_REQUEST_TEMPLATE.md` に従った Draft PR を作成する。

- 未コミットの変更があれば、先に `commit` スキルでコミットする
- Draft PR として作成し、自分自身をアサインする
- タイトルと本文は日本語で書く
- タイトルと本文は、コミットメッセージではなく、ベースブランチとの差分全体を元に書く。コミットメッセージは途中経過を含み、最終的な変更内容と一致しないことがあるため
- タイトルは PR 全体の変更内容を 1 文で簡潔に書く
- 本文は簡潔に書く
  - 変更点を箇条書きで並べ、各項目は 1 行に収める
  - レビュアーが差分から読み取れる細部や、実装の経緯は書かない
- テンプレートにあるセクションは、書く内容がなくても削除しない
